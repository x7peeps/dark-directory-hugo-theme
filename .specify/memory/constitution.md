# Dark Directory Hugo Theme Constitution

> 基于 Hugo + Relearn 的暗色目录主题「扩展层」（技术博客 / 知识库 / 产品宣传 / 个人品牌官网）。

## Core Principles

### I. 扩展层定位 (Extension-Layer, Not Fork)
- 本主题是 Relearn 之上的扩展层：只通过 `layouts/`、`static/css/custom.css`、`static/js/custom.js` 做覆盖式定制
- 不复制/改写 Relearn 核心模板；保持与上游的升级路径畅通

### II. 视觉一致性 (Visual Consistency)
- 暗色基调与既有设计 token 统一；新增组件复用现有配色/间距/圆角体系，不引入第二套视觉语言
- 改动 UI 的提交须附正常/悬停/移动端的最小对照说明

### III. 内容与产品共存
- 保持「内容页（博客/文档）」与「产品页（宣传/品牌）」两类版式同时可用；改动不得破坏任一侧

### IV. 资产合规 (Asset Compliance)
- 新增图片/字体/第三方资源须记录来源与许可，避免不明版权素材入仓

## Governance
